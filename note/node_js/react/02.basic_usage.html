02.基本使用

2.1 构建一个组件

  • React中，可以使用函数创建组件，这种函数接收输入参数，同时返回一个React Element对象

    • 通过从root开始的渲染函数，可以构建出一颗渲染树，这棵树由节点组成，每个节点代表一个组件，React可以跨平台构建，因此在渲染树中的是UI的表达方式(原语)，这些原语可以帮助标识渲染为某个平台的

    • 尽管渲染树可能在不同的渲染过程中有所不同，但通常这些树有助于识别 React 应用程序中的顶级和叶子组件。顶级组件是离根组件最近的组件，它们影响其下所有组件的渲染性能，通常包含最多复杂性。叶子组件位于树的底部，没有子组件，通常会频繁重新渲染

      export default function Avatar({ avatar, name }) {
    return (
        <img className="avatar" src={avatar} alt={name} />
    )
}

  • 引入响应式：为了更好地在数据变化时重新执行这个函数，React提供了useState等hook方法，实现源码见ReactFizzHooks.js

  • useState(initialValue)：用于创建一个状态变量，返回一个状态值和修改状态值的函数，状态值不应直接修改

    • 这个函数返回一个[v, setV](解包)，在调用修改状态值的函数setV时，React会修改状态值v，并通知重新执行从root结点开始的渲染函数，并进行虚拟树的比较

    • 这个函数需要提供一个初始值initialValue，这个值将作为第一次渲染的值，之后每次变化会读取到当前缓存的状态值

    • 每个渲染函数中都有一个缓存的状态数组，在第一次执行时，调用useState会向其中添加值，在之后执行时会依次将其中的状态按顺序提供给每个useState，每次调用渲染函数时的状态有变化，因此最终渲染结果会不同

    • setV(v)：react仅检查状态值的地址引用是否变化，决定是否要重新渲染，因此setV需要完整替换，这个函数会将新传入的值作为状态值

      • 对于数组变量list，你需要使用list.map(item=>item+1)来创建新的数组作为传入值，或者使用list.fliter、list.splice这种会返回新数组的函数
      • 对于对象obj，你需要使用展开语法，{...obj, name: 'newName'}来修改单个值。...obj是浅拷贝，这也意味着如果你需要深层更新，需要{...obj, parents: {...obj.parents, fatherName: 'newName'}
      • 这确实很繁琐，immer是一个流行的修改库，它通过代理的方式，帮助你创建这样的新对象

    • setV((v)=>newV)``useState的返回值被解包了，因此你在使用v时，这个值是确定的，这导致了回调陷阱

      • 你在当前渲染函数中直接使用v时，它不会因为你使用了setV而被改变，读取到的永远是当前的状态值，这和vue不同，也就是说setV(v+1)无论被调用多少次，结果都是当前的v+1
      • 因此setV还支持传入(v)=>v+1这样的函数，这个函数传入内部状态参数，并将返回值作为新状态值
      export default function RootApp() {
    const [num, setNum] = useState(0);
    const onClick1 = () => {
        setNum(num+1);
        setNum(num+1);
        setNum(num+1);
    }
    const onClick2 = () => {
        setNum((num)=>num+1);
        setNum((num)=>num+1);
        setNum((num)=>num+1);
    }
    return (
        <div>
        <button onClick={onClick1}>{num}</button>
        <button onClick={onClick2}>{num}</button>
        </div>
    )
}

    让渲染函数纯粹

    对于一个渲染函数而言，它应该只接收状态并根据输入值渲染得到对应的组件，也就是纯函数，输入相同则输出相同。为此，实现时最好不引入全局变量，如果组件被多次调用，结果难以预测。全局变量完全可以作为一个输入

  • useRef(initialValue)：你如果想让组件“记住”某些信息，但又不想让这些信息触发新的渲染时使用useRef。这个函数用于创建一个引用变量，它有一个current属性，这个属性的值是引用变量的当前值，你可以直接修改它

    • 引用变量不像状态变量，修改不会触发组件的重新渲染，但在回调等函数中读取到的值确实变化了

    • 这可以作为React观察不到的缓存变量，你可以在用户操作时缓存值，并确保在重新渲染后，缓存的值依旧存在

    • 通常用于存储外部通信变量，比如timeoutId

    • 另一常见用途是通过jsx元素的ref属性，获取界面元素的引用，操作DOM

    • useRef理论可以在useState的基础上实现，使用时可以把它当做没有状态修改函数的useState变量，React底层实际上为useRef单独写了逻辑

      export default function TimeTracker() {
    const [num, setNum] = useState(0);
    const timeoutId = useRef(null);
    const onClick = () => {
        timeoutId.current = setTimeout(()=>{
            setNum(num+1);
        }, 1000)
    }
    const clear = () => {
        clearTimeout(timeoutId.current);
    }
    return (
        <div>
            <button onClick={onClick}>{num}</button>
            <button onClick={clear}>clear</button>
        </div>
    )
}

  • useEffect(fn, deps)：用于创建一个副作用函数，这个函数会在组件渲染时执行，通常用于处理副作用

    • deps是依赖数组，凡是在fn直接或间接使用的来自fn作用域外的可变值都应该添加在内，确保这些依赖变化后重新执行。每次渲染时会判断deps是否改变，如果改变，则执行fn

      • useRef、状态改变函数setState可以不包含在内，因为这些值被缓存起来了，引用不会改变

    • useEffect(fn, deps)实际上和vue中的watchEffect类似，跟踪依赖变化重新执行作用函数，这个函数会在第一次渲染时执行

    • 当deps为[]时，函数仅在初始化时执行一次，后续不再执行，相当于创建的生命周期钩子

      export default function RandomColorBlock() {
    const color = [];
    useEffect(()=>{
        for(let i=0; i<6; i++){
            color.push(Math.floor(Math.random()*16).toString(16));
        }
    }, [])
    return (
        <div style={{backgroundColor: `#${color.join('')}`}}>{color.join('')}</div>
    )
}

      状态驱动作用

      useEffect是明显地以状态驱动的函数，传递给useEffect的回调不应该是异步函数(有立即返回值)

      • 如果有需要异步的操作，应该在内部使用异步函数
      • 如果需要在异步作用1完成后，再完成同步作用2，也可以用状态驱动，使用一个loading状态变量，在异步完成后，修改loading，然后基于状态更改执行作用2
      export default function RandomColorBlock({index}) {
    // 在异步加载完成后，设置标注色
    const [color, setColor] = useState([]);
    const [isLoading, setIsLoading] = useState(true);
    useEffect(()=>{
        const getRandomColor = async ()=>{
            const color = await fetch(COLORS_URL);
            return color.json();
        }

        getRandomColor().then((color)=>{
            setColor(color);
            setIsLoading(false);
        })
    });

    useEffect(()=>{
        if (!isLoading) {
            setMarkers(color, index);
        }
    },[isLoading, index]);

    return (
        <div style={{backgroundColor: `#${color.join('')}`}}>{color.join('')}</div>
    )
}

  • useEffectEvent(fn)：用于在useEffect中将不需要响应式的逻辑提取出来

    • 对于useEffect而言，你需要将所有的外部响应式变量都放入deps数组，数组变大可能引入一些不必要的执行，而deps不完全添加又会被依赖项检查工具检测出来

    • 虽然依赖项检查可以被禁用// eslint-disable-next-line react-hooks/exhaustive-deps，但在未来更新代码时很可能引入奇怪的未执行bug

    • React官方提供了useEffectEvent，可以将部分代码的依赖项检测跳过

    • 方法的返回值和正常函数一样使用，但也仅应该在当前组件的Effect中调用

      export default function TextBlock() {
    const [isDark, setIsDark] = useState(false);
    const [name, setName] = useState('default name');
    const name_input = useRef<HTMLInputElement>(null);
    toggle = useEffectEvent((toggle_name: string)=>{
        alert(`${isDark?'dark mode':'light mode'}, ${toggle_name}`);
    })
    useEffect(()=>{
        toggle(name);
    }, [name])
    return (
        <div>
            <input type="chcekbox" onChange={(e)=>setIsDark(e.target.checked)}/>
            <input type="text" ref={name_input}/>
            <button onClick={()=>setName(name_input.value)}>change name</button>
        </div>
    )
}

  • useCallback(fn, deps)：用于创建一个缓存的回调函数，这样每次渲染时，回调函数将缓存起来，下次渲染时，如果输入相同，则返回缓存的回调函数

    • 用途：

      • useCallback可以确保deps未修改时，每次传递给子组件的函数引用地址相同，跳过组件的重新渲染
      • 另外，useEffect需要声明所有的外部函数和变量，缓存外部函数也可以避免useEffect中的函数引用地址修改，导致useEffect重复触发，当然React推荐将函数声明移入useEffect中

    • 必须传入deps，如果不希望变化，请传入空数组[]，如果传入undefined，React会认为每次都需要更新，和不包裹一样

    • 不应该在循环中使用useCallback(新的循环不一定能和之前的渲染循环缓存对应上)，如果有批量创建不同的回调的需求，请使用子组件

      export default function ClickBlock() { 
    const [count, setCount] = useState(0);
    const callback = useCallback(() => { setCount((v)=>v+1); }, [setCount]);
    return (
        <div>
            <div>{count}</div>
            <Button onClick={callback}></Button>
        </div>
    )
}

2.2 动态渲染

  • 对于一个组件而言，动态渲染应该是最基本的需求，由于JSX的简单语法，React中可以直接操作组件的属性值，因此基本使用从动态渲染开始

    • 通过判断逻辑来选择渲染：如果需要在内部判断渲染，可以使用{}包裹判断逻辑；如果逻辑复杂，可以使用变量或组件预处理

      • 如果{}中的判断逻辑返回false，React不会进行渲染，就像null和undefined
      • 如果{}中的判断逻辑返回true，React会返回对应的值，比如下方的isLogged && name，当isLogged为true时，会返回name
      export default function InfoBlock() {
    const [isLogged, setIsLogged] = useState(false);
    const callback = useCallback(() => { setIsLogged((v)=>!v); }, [setIsLogged]);
    const avatar = 'https://picture.com/avatar.png';
    const name = '小明';
    let avatarImg = null;
    if (isLogged) { 
        avatarImg = <img src={avatar} alt="avatar" />;
    }
    return (
        <>
            <button onClick={callback}>
            {isLogged ? 'Logout' : 'Login'} {isLogged && name }
            </button>
            {avatarImg}
        </>
    )
}

2.3 事件

  • React支持为标签添加事件处理函数，这些事件处理属性需要传入js函数

    事件的传播

    在react中，最终的渲染树会直接转换为DOM树，鉴于大部分事件都会传播，因此组件能捕获子组件的事件
