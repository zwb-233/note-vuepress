主流系统

linux

远程连接linux

  • 使用xRDP结合SSH隧道，默认自带的系统远程连接无法创建虚拟屏幕，需要保持屏幕常亮
# 在目标Ubuntu系统上，安装xrdp
sudo apt update
sudo apt install xrdp -y

# 为减少资源占用或有安装图形化界面需求，推荐安装 XFCE 桌面环境
sudo apt install xfce4 xfce4-goodies -y
echo "xfce4-session" >~/.xsession

# 启用并检查xRDP服务状态
sudo systemctl enable --now xrdp
sudo systemctl status xrdp

# 默认情况下，不使用ssh隧道
sudo ufw allow 3389/tcp
sudo ufw enable

# 使用ssh隧道
sduo ufw deny 3389
ssh -L 3389:localhost:3389 linux用户名@linux的ip地址
# 此时直接通过localhost:3389连接
  • 可以通过windows的自带的远程连接工具(基于RDP)连接，连接之后，输入linux用户名和密码连接

windows

远程连接windows

  • windows支持远程连接，如果是专业版，可以直接在设置中使用远程桌面，如果是家庭版，可以下载superRDP2，激活对应功能
  • 在使用远程连接时，应该保证息屏不会中断上网，在控制面板设置网络设备的供电；同样保证电脑不会进入休眠模式，在设置中修改，每次离开使用win+l锁定

问题解决

磁盘错误

  • 使用chkdsk c: /f命令,其中c:表明修复c盘，重启后会进入修复模式，使用图形化磁盘修复工具无效
